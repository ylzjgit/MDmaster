# 公众号排版指南

公众号编辑器只认**行内样式**，不认 class 和 style 标签。MDMaster 在渲染时已经把每个标签的样式写进 style 属性，所以粘贴过去不会掉样式。

## 为什么能直接粘贴

- 每个标题、段落、列表、表格都带内联样式
- 代码高亮通过 span 的颜色内联实现
- 图片、分隔线、引用块都会保留形态

## 常见问题

**Q：粘贴后字体变了？**

公众号会保留 inline 的 font-family，若要保持一致，请在主题中选择「微信绿」等预设主题。

**Q：链接为什么点不动？**

微信正文不支持外链跳转，这是平台限制。链接文字会保留，可以在文末统一放置参考资料。

**Q：本地图片怎么处理？**

本地图片地址无法被微信读取，粘贴后需要手动在微信编辑器中重新上传图片。

## 小技巧

- 正文宽度建议不超过 760px，阅读体验更好
- 每个二级标题之间保持 1~2 段正文，避免长文疲劳
- 关键结论用 **加粗** 或引用块强调
