# MDMaster 使用指南

MDMaster 是一个专注中文写作的 Markdown 编辑器：**左边写、右边看**，滚动双向联动，渲染结果可以**一键粘贴到微信公众号**。

> 提示：把光标放在任意段落，右侧预览会自动滚到对应位置；点击右侧任意段落，光标会跳回源码。

## 一、核心能力

- **左右联动**：滚动一边，另一边自动跟随，不会迷路
- **智能目录**：右侧目录自动生成，滚动时高亮当前章节，点击即可跳转
- **文件管理**：左侧文件树管理多个文档与文件夹，支持新建、重命名、拖拽移动
- **全键盘操作**：标题、加粗、代码、表格、图片……常用语法都有快捷键
- **公众号排版**：渲染结果全部转成内联样式，复制后直接粘进微信编辑器

## 三、公众号发布流程

1. 写好文章，右侧预览确认效果
2. 在工具栏选择配色主题（微信绿 / 科技蓝 / 简约黑白 / 暖阳橙）
3. 点击右上角 **复制到公众号**（Ctrl + Shift + C）
4. 打开微信公众号后台，在正文区域 **Ctrl + V** 粘贴
5. 图片如果需要，可在微信编辑器中重新上传
