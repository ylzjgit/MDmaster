# 代码块与表格

## 代码块

在 Markdown 中使用三个反引号包裹代码，后面可以跟语言名获得高亮。

支持的语言包括：JavaScript、TypeScript、Python、Java、Go、Rust、C、C++、C#、Bash、JSON、YAML、HTML、CSS、SQL、Markdown、Diff。

示例（Python）：

```python
def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print([fib(i) for i in range(10)])
```

## 表格

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| title | string | 是 | 文章标题 |
| author | string | 否 | 作者名 |
| tags | string[] | 否 | 标签列表 |
| createdAt | number | 是 | 时间戳 |

## 行内代码与引用

使用 `markdown-it` 渲染，用 `highlight.js` 做高亮，最后把 class 全部转成内联样式。
